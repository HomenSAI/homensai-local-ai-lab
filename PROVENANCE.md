## English

**What is original.** Everything in this repository that is code or documentation was written for this project and is our own work: the console (`console/`), the report builder (`scripts/build_live_report.py`), the versioner and Git setup (`scripts/versioner.py`, `scripts/setup_git.py`), the installer (`scripts/install.py`), the public-results generator, the translation layer (`console/i18n*.js`), the compose files and Dockerfiles, and all texts. Each of them was designed around this project's architecture (a file-based result protocol, a supervising AI instead of a built-in judge, separate projects for tests and video) and was not copied from another project.

**What is not ours, and how it is used.** The server runs third-party programs that are **not included as source or binaries in this repository**; they are downloaded at build time from their official locations at pinned versions:

| Component | Used as | Pin |
|---|---|---|
| llama.cpp (MIT) | built in a Docker image | commit in `.env` |
| PrismML llama.cpp fork | built in a Docker image, only for the Bonsai model | commit in `.env` |
| llama-swap (MIT) | official release archive, SHA-256 checked | v260 |
| Gitea (MIT), nginx, Python, Alpine, CUDA base images | official images | tags in `docker-compose.yml` |
| whisper.cpp, stable-diffusion.cpp (MIT) | built in optional images | commits in `.env` |
| Open WebUI, ComfyUI, Wan 2.1 | optional, installed separately by the user (Video Studio: ComfyUI and Wan in its own project) | see `legal/NOTICE-THIRD-PARTY.md` |

Their licenses stay with their authors; see `legal/NOTICE-THIRD-PARTY.md`. Model weights are never included.

**Test content.** The tasks used for the published results were written or generated by us (generated arithmetic, chemistry and physics problems with computed answers, our German items, our long-context filler); they were not copied from public benchmark datasets.

**How AI was involved.** The code and the tests were written with the help of AI assistants - mainly Claude (Anthropic), and some early parts such as the first compose files and the telemetry exporter with other assistants - under the direction and review of the author, Serhii Khomenko (<https://homensai.com>, info@homensai.com); the author is responsible for what is published. Using an AI assistant does not change the licenses: code MIT, results and texts CC BY 4.0 with credit to <https://homensai.com>.

**Automatic check.** `scripts/build_github_package.py` fails the package build if a file outside `legal/` carries a third-party copyright or license header (`Copyright (c)`, `SPDX-License-Identifier`, `Licensed under`), a secret, or a personal path. This is a safety net, not a legal proof: please read the code before relying on this statement, and tell us about anything that looks copied.

**Что не наше и как используется.** Сервер запускает сторонние программы, которые **не входят в репозиторий ни исходниками, ни бинарниками**; они скачиваются при сборке из официальных источников в зафиксированных версиях (таблица выше). Их лицензии остаются у авторов: `legal/NOTICE-THIRD-PARTY.md`. Веса моделей никогда не включаются.

**Содержимое тестов.** Задачи, по которым получены опубликованные результаты, написаны или сгенерированы нами (сгенерированные задачи по математике, химии и физике с вычисленными ответами, наши немецкие задания, наш наполнитель для длинного контекста); они не скопированы из публичных наборов бенчмарков.

**Участие ИИ.** Код и тесты написаны с помощью ИИ-ассистентов — в основном Claude (Anthropic), а некоторые ранние части, такие как первые файлы compose и экспортёр телеметрии, — с помощью других ассистентов, по поручению и под проверкой автора; за публикуемое отвечает автор. Использование ИИ-ассистента не меняет лицензий: код MIT, результаты и тексты CC BY 4.0 со ссылкой на <https://homensai.com>.

**Автоматическая проверка.** `scripts/build_github_package.py` останавливает сборку пакета, если в файле вне `legal/` есть чужой заголовок авторских прав или лицензии (`Copyright (c)`, `SPDX-License-Identifier`, `Licensed under`), секрет или личный путь. Это страховка, а не юридическое доказательство: прочитайте код, прежде чем полагаться на это заявление, и сообщите нам обо всём, что выглядит скопированным.
