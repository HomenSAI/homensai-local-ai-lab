# Политика безопасности

Другие языки: [English](SECURITY.md) · [Deutsch](SECURITY.de.md)

## Модель угроз

Консоль (порт 8766) и шлюз (порт 8080) рассчитаны на `127.0.0.1` или **доверенную локальную сеть**. Они не защищены для работы в интернете. **Никогда не публикуйте порты 8766, 8080, 3010 или 8767 в интернет**; ограничьте правило брандмауэра своей подсетью.

Как консоль защищает себя (`console/security.py`, `console/container_server.py`):

| Угроза | Защита |
|---|---|
| Веб-страница в браузере оператора запускает, останавливает или выгружает модели (межсайтовая подделка запроса) | Каждый `POST` должен иметь `Content-Type: application/json` (чужая страница не может отправить такой запрос без предварительного запроса CORS, который консоль никогда не разрешает), не должен приходить с другого источника (проверяются `Origin`, `Sec-Fetch-Site`), иначе ответ — `415` / `403` |
| DNS rebinding (чужое имя хоста, указывающее на ваш ПК) | В качестве `Host` принимаются только `localhost`, IP-адреса и имена из `AI_CONSOLE_ALLOWED_HOSTS`; всё остальное получает `421` (`/health` — исключение для проверки состояния контейнера) |
| Консолью пользуется другой человек в локальной сети | Задайте `AI_CONSOLE_PASSWORD` в `.env`: тогда консоль требует HTTP Basic-аутентификацию (любое имя пользователя) для всего, кроме `/health`. Используйте его всегда, когда `AI_CONSOLE_BIND_IP` не равен `127.0.0.1`. Basic-аутентификация передаёт пароль без шифрования: в недоверенной сети поставьте перед консолью обратный прокси с TLS или VPN |
| Встраивание во фреймы, угадывание типа содержимого, внедрённые скрипты | Каждый ответ содержит `Content-Security-Policy` (только свои скрипты, без фреймов), `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer` |
| Выход за пределы каталога в `/report/` и `/legal/` | Пути разрешаются и должны оставаться внутри папки; покрыто тестами |
| Сокет Docker | См. ниже |

### Сокет Docker

Контейнер консоли монтирует `/var/run/docker.sock`. Флаг `read_only` у этого монтирования **не** является границей безопасности, а сокет равнозначен правам root на хосте. Консоль использует его, чтобы получать список контейнеров и выполнять одну фиксированную команду внутри контейнера модели (`curl` к адресу `/health`, `/slots` или `/metrics` у `llama-server` на `127.0.0.1`). Любую другую команду код отклоняет: имя контейнера должно быть простым именем Docker, а URL — соответствовать этой фиксированной форме (`docker_exec_read`, покрыто тестами). Контейнер работает с `cap_drop: ALL`, `no-new-privileges` и корневой файловой системой только для чтения. И всё же **тот, кто получит полный контроль над консолью, получит Docker на этом ПК**, поэтому держите доступ из сети минимальным и задайте пароль.

### Известные ограничения

- У шлюза (llama-swap, порт 8080) нет никакой аутентификации; он опубликован только на `127.0.0.1`. Не меняйте это без обратного прокси с аутентификацией.
- `scripts/setup_git.py` один раз передаёт сгенерированный пароль администратора Gitea в `docker exec` в командной строке; другие пользователи демона Docker на том же ПК могут ненадолго его увидеть. Пароль хранится в `secrets/gitea-admin.txt` (игнорируется Git).
- У Basic-аутентификации нет ограничения частоты попыток и нет блокировки.

## Чего репозиторий никогда не должен содержать

Пароли, токены, SSH-ключи (папка `secrets/` игнорируется Git), `.env` с личными значениями (в репозиторий попадает только `.env.example`; `.env` игнорируется, поэтому в нём можно хранить `AI_CONSOLE_PASSWORD`), веса моделей, личные данные. Если вы что-то такое найдёте, сообщите, пожалуйста, как описано ниже.

Напишите на info@homensai.com (автор: Serhii Khomenko, <https://homensai.com>) и опишите проблему, затронутый файл и способ воспроизведения. Вы получите ответ как можно скорее; пожалуйста, дайте разумное время на исправление до раскрытия.

## Цепочка поставок

Базовые образы, коммиты llama.cpp / whisper.cpp / stable-diffusion.cpp и llama-swap (SHA-256 релиза) закреплены; файлы моделей перед использованием следует сверить с суммами SHA-256 в `MODELS.md` или на странице модели. `MANIFEST.json` перечисляет размер и SHA-256 каждого файла репозитория; `python scripts/make_manifest.py --check` проверяет его (CI делает то же самое). `python scripts/install.py doctor` никогда не скачивает тестовый образ CUDA размером 5,6 ГБ, если вы не передали `--pull`.
