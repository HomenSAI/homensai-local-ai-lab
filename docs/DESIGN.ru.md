# Почему сделано именно так

Другие языки: [English](DESIGN.en.md) · [Deutsch](DESIGN.de.md) · Структура: [ARCHITECTURE.md](ARCHITECTURE.md)

Для каждого решения указаны причина и место, где живёт значение. Значения с пометкой *измерено* получены нашими прогонами на RTX 3080 (10 ГБ) и на другом железе их нужно измерять заново.

| Решение | Почему | Где |
|---|---|---|
| **Одна модель в видеопамяти за раз** | в 10 ГБ помещается одна модель 7–27B с длинным контекстом; две модели дали бы крошечные контексты или откат на CPU. llama-swap выгружает старую модель перед загрузкой следующей | `config/llama-swap.yaml` (`ttl`, `unloadTimeout`) |
| **llama-swap перед llama.cpp** | даёт API, совместимый с OpenAI, на одном порту, загружает модели по запросу и выгружает после простоя, так что любой чат-клиент или ИИ-ассистент работает с сервером, не зная о процессах | `Dockerfile.llama-swap`, порт 8080 |
| **Зафиксированные версии и контрольные суммы** | коммиты llama.cpp, релиз llama-swap (SHA-256) и дайджест базового образа зафиксированы, чтобы результат можно было повторить через месяцы | `.env`, `Dockerfile.*` |
| **Модели в томе Docker (ext4)** | привязка диска Windows через WSL читалась на ~22–45 МБ/с, холодная загрузка занимала 6–14 минут; из тома — 11–29 секунд (*измерено*) | `docker-compose.yml`, `llm-models-fast` |
| **Размеры контекста взяты из тестов, а не из карточки модели** | контекст профиля — самое большое окно, при котором модель стартовала, нашла 3 из 3 спрятанных фактов на 80% заполнения и сохранила скорость на GPU (*измерено*, KV-кэш f16 / q8 / q4) | `config/llama-swap.yaml`, этап «Максимальный стабильный контекст» |
| **Только GPU, минимум 64K для поздних этапов** | перелив в RAM даёт 1–3 токена/с — это не рабочий сервер; правило автора сохраняет честность сравнения | [METHODOLOGY.ru.md](METHODOLOGY.ru.md) |
| **Нет встроенного LLM-судьи** | модель, оценивающая модели, добавляет неизмеренную ошибку. Проверяющие функции детерминированы (вычисленные ответы, точное совпадение, запуск тестов); вместо этого результаты просматривает ИИ-супервизор, а его вывод записывается | [AI_OPERATOR.ru.md](AI_OPERATOR.ru.md) |
| **ИИ-ассистент как оператор, без плагина** | сервер предоставляет только обычные интерфейсы (оболочка, REST, API OpenAI, файлы). Любой ассистент, умеющий выполнять команды, может им управлять, а без него сервер тоже работает | [AI_OPERATOR.ru.md](AI_OPERATOR.ru.md) |
| **Консоль и отчёт на стиле HomenS.AI** | один дизайн для всех проектов HomenS.AI: цвета, шрифты, логотип, шапка, подвал и обе темы берутся из пакета стиля (`console/style/`, версия 1.4.0, закреплена метой `<meta name="homensai-style">`); в `app.css` и `report.css` — только раскладка на токенах стиля; без внешних адресов | `console/style/`, `console/app.css`, `report/report.css` |
| **Консоль, сборщик и версионер — только стандартная библиотека Python** | нет зависимостей, которые надо обновлять и проверять, мала поверхность атаки, образы собираются за секунды | `console/`, `scripts/` |
| **Результаты никогда не перезаписываются** | разные тесты хранятся раздельно; архив SQLite хранит историю; Git хранит каждую версию отчётов (`vNNNN`, `stage-<этап>-done`, `final-<дата>`), так что любой прошлый отчёт восстановим | `scripts/build_live_report.py`, `scripts/versioner.py` |
| **Файловый протокол результатов** | инструменту тестирования достаточно дописывать JSON-строки и маркер в лог; план, полоса прогресса и оценка времени берутся из файлов, поэтому инструменты заменяемы | [RESULTS_FORMAT.md](RESULTS_FORMAT.md) |
| **Генерация видео — отдельный проект** | видео занимает всю видеокарту, имеет свой цикл релизов, свои 10 ГБ файлов моделей и свою аудиторию | репозиторий Video Studio |
| **Текст интерфейса на одном языке, перевод на лету** | нет этапа сборки; данные пользователя исключены из перевода, поэтому промпты и ответы остаются точными; `scripts/check_i18n.js` находит пробелы | `console/i18n*.js` |
| **По умолчанию привязка к локальному адресу, защита каждого запроса, необязательный пароль** | инструмент для доверенного ПК или сети. Консоль принимает только безопасные имена `Host` и POST-запросы `application/json` с того же источника, поэтому страница в браузере оператора не может запустить или остановить модель; `AI_CONSOLE_PASSWORD` добавляет HTTP Basic для работы по локальной сети. Это не замена межсетевому экрану: никогда не открывайте консоль в интернет | `console/security.py`, [SECURITY.md](../SECURITY.md) |
| **Сокет Docker подключён к консоли** | консоль должна видеть, какие контейнеры держат GPU и работает ли контейнер видео, и читает состояние llama-server внутри контейнера через `docker exec`. Флаг `read_only` не граница безопасности, а сокет равносилен root, поэтому консоль отправляет через него только один фиксированный вид команд (curl к служебным адресам `127.0.0.1` контейнера с простым именем), работает без привилегий (`cap_drop: ALL`, `no-new-privileges`), а проверки пароля и `Host` защищают каждый вызов. Кто получит полный контроль над консолью, получит Docker | `docker-compose.yml`, `console/container_server.py` |
| **Результаты CC BY-NC 4.0, код PolyForm Noncommercial 1.0.0** | результаты и код можно свободно использовать в некоммерческих целях, всегда со ссылкой на автора; коммерческое использование — по соглашению с автором | `legal/` |
